# 安全概述

本页简要介绍如何保障树莓派设备的安全，并提供指向更详细信息的链接。

## 安全架构

树莓派的安全架构确保：只有经过身份验证的启动代码才能在完成配置的树莓派设备上运行；磁盘加密密钥受到保护；信任链会验证启动过程的每个阶段。

更多信息，请参阅[安全架构](an-quan-jia-gou.md)。

## 安全启动配置器

树莓派开发了一款配置工具，用于简化以下过程：

* 设置**安全（验证）启动**（Secure Boot），建立硬件信任链，确保在设备启动序列期间只运行经过身份验证的代码。
* 设置**磁盘加密**，保护存储在持久性介质（如存储卡或 USB 驱动器）上的数据。
* 以简化的配置和部署流程**配置多台树莓派设备**。

更多信息和操作说明，请参阅[安全启动配置器](an-quan-qi-dong-pei-zhi-qi.md)。

## 运营安全

你可以配置树莓派设备，通过以下方式防止未经授权的访问并改善日常安全卫生：

* 用户和访问管理，包括身份验证、用户账户、组和权限。
* 定期更新操作系统和软件。
* 通过强化 SSH 实现安全的远程访问。
* 防御可疑活动和暴力破解攻击。

更多信息和操作说明，请参阅[运营安全](yun-ying-an-quan.md)。

## 使用 UFW 的防火墙

在树莓派设备上使用**简单防火墙（Uncomplicated Firewall，UFW）**配置数据包过滤防火墙，有助于加固系统。它可用于将网络访问限制为仅必要的服务，并通过阻止不需要或恶意的连接来缓解外部威胁。

更多信息和操作说明，请参阅[使用 UFW 的防火墙](ufw-fang-huo-qiang.md)。

## 一线安全披露

树莓派遵循结构化的漏洞报告和管理流程。作为该流程的一部分，我们会定期跟踪并整合来自 Debian 的安全更新。

树莓派在我们网站上公布官方安全漏洞披露信息。更多信息，请参阅[安全公告](https://www.raspberrypi.com/security#security-advisories)和[树莓派系统 — CVE 报告](https://raspberrypi.github.io/cve-list/)。

要报告树莓派上的安全问题，请发送电子邮件至 [security@raspberrypi.com](mailto:security@raspberrypi.com)。更多信息，请参阅[报告漏洞](https://www.raspberrypi.com/security/#reporting-a-vulnerability)。

如需通过电子邮件接收树莓派产品重大安全漏洞的通知，请使用我们安全页面上的[接收安全漏洞通知](https://www.raspberrypi.com/security/#subscribe)表单进行订阅。

## 软件物料清单

软件物料清单（SBOM）列出软件应用程序中的所有组件，并包含每个组件的元数据，例如名称、版本、供应商、许可证和唯一标识符。这些信息以开放标准、机器可读的格式提供。

我们为每个版本的树莓派系统提供 SBOM。你可以从[树莓派系统下载页面](https://www.raspberrypi.com/software/operating-systems/)下载 SBOM 文件。
