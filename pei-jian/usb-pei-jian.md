# USB 配件

树莓派提供以下高质量、可靠的 USB 配件，可与树莓派及其他计算机配合使用：

* 树莓派 [USB 3 集线器](#usb-3-集线器)，用于扩展 USB 连接。
* 树莓派 [闪存盘](#闪存盘)，用于便携存储。

## USB 3 集线器

树莓派 USB 3 集线器通过将一个 USB-A 接口扩展为四个 USB-A 接口，为你的设备提供额外连接。通过 USB 3 集线器连接的设备，其识别方式与直接连接到主机系统时相同，无论主机是树莓派设备还是其他计算机。

在使用总线供电时，USB 3 集线器可从其上游 USB 接口汲取高达 900 mA（4.5 W）的功率。这 4.5 W 由所有四个下游 USB 3.0 接口共享，足以支持低功耗外设，例如大多数鼠标和键盘。

为支持高功率外设和设备，USB 3 集线器还包含一个可选的 USB-C 电源输入，可在需要时为下游接口提供外部供电。

### USB 3 集线器功能

树莓派 USB 3 集线器提供 USB 扩展能力，具备高速数据传输、灵活的供电选项，并兼容 USB 3.0 和 USB 2.0 接口。与这些功能相关的关键规格总结在下表中。

树莓派 USB 3 集线器功能及对应规格

| 功能 | 规格 |
| ---- | ---- |
| **USB 扩展** | 提供四个下游 USB 3.0 Type-A 接口；一根 8 cm 固定线缆上的上游 USB 3.0 Type-A 接头。 |
| **速度** | 提供高达 5 Gb/s 的数据传输速度。 |
| **供电** | 提供最高 900 mA、5 V（4.5 W）的电流，取自集线器所连接的设备；通过可选的 USB-C 电源输入自供电时，可提供最高 5 V、3 A（15 W）的功率。 |
| **兼容性** | 适用于 USB 3.0 Type-A 接口，并向后兼容 USB 2.0。 |

## 闪存盘

树莓派闪存盘是一款 USB 3.0 闪存盘，提供便携存储，可用于传输文件、创建备份或运行操作系统。闪存盘有两种存储容量（128 GB 或 256 GB），使用非易失性闪存，在断开连接后仍能保留数据。

![树莓派闪存盘](.gitbook/assets/flash-drive-hero.png)

树莓派闪存盘

### 闪存盘功能

树莓派闪存盘轻巧便携，采用紧凑的金属设计，可挂在钥匙圈或挂绳上。两种容量选项均提供可靠的便携存储性能，并兼容 USB 3.0 和 USB 2.0。与这些功能相关的关键规格总结在下表中。

树莓派闪存盘功能及对应规格

| 功能 | 规格 |
| ---- | ---- |
| **紧凑外形** | 重量不到 6 克；尺寸见[闪存盘尺寸](#闪存盘尺寸)。 |
| **存储选项** | 提供 128 GB 和 256 GB 两种容量，使用非易失性闪存。 |
| **性能** | 因存储容量而异。详情见[闪存盘功能](#闪存盘功能)中的性能表。 |
| **兼容性** | 适用于 USB 3.0 Type-A 接口，并向后兼容 USB 2.0。 |
| **SMART 报告** | 支持可通过 `smartctl` 等工具读取的 ATA 风格健康报告。更多信息见 [SMART 报告](#闪存盘-smart-报告)。 |

树莓派闪存盘提供高 IOPS（每秒输入/输出操作数），可快速访问小文件。它还能为启动操作系统和运行应用程序等计算任务提供响应迅速的性能。下表总结了树莓派闪存盘每种存储容量（128 GB 或 256 GB）的关键性能特性。

树莓派闪存盘基于存储容量的性能特性

| 性能特性 | 128 GB | 256 GB |
| ---- | ---- | ---- |
| **4 kB 随机读取** | 16,000 IOPS | 18,000 IOPS |
| **4 kB 随机写入** | 21,000 IOPS | 22,000 IOPS |
| **顺序写入速度（持续）** | 75 MB/s | 150 MB/s |

### 闪存盘 SMART 报告

树莓派闪存盘使用的 USB 控制器支持 12 字节 ATA 直通 SCSI 命令，可用于评估驱动器自身的健康状况。

#### 查看 SMART 数据

读取和显示 SMART 报告的推荐应用程序是 `smartctl`，它包含在 `smartmontools` 软件包中。要显示完整的 SMART 报告，请运行以下命令：

```bash
sudo smartctl -d sat,12 -x /dev/sda
```

`-d sat,12` 参数指示 `smartctl` 使用 SAT-12 ATA 直通协议与 USB 控制器通信。
