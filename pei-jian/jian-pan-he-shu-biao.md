# 键盘和鼠标

## 开始使用你的键盘

我们的官方键盘包括三个主机 USB 接口，可用于连接外部设备，如 USB 鼠标、USB 存储设备和其他 USB 受控设备。

该产品的 micro USB 接口用于连接树莓派。通过键盘内置的 USB 集线器，树莓派可以控制这三个 USB Type A 接口并为其供电。

![键盘尾端](https://www.raspberrypi.com/documentation/accessories/images/back-of-keyboard.png)

### 键盘功能

树莓派键盘有三个锁定键：`Num Lock`、`Caps Lock` 和 `Scroll Lock`。右上角有三个 LED 指示灯，指示哪些锁定处于启用状态。

![num cap 和 scroll](https://www.raspberrypi.com/documentation/accessories/images/num-cap-scroll.png)

`Num Lock` 可使用字母键上标注的红色数字键，等效于一个数字小键盘。按 `Num Lock` 键可启用或禁用此模式。

`Caps Lock` 可输入大写字母；在该模式下按 `Shift` 键可输入小写字母。按 `Caps Lock` 键可启用或禁用此模式。

`Scroll Lock (ScrLk)` 可使用光标键浏览网页和电子表格，无需鼠标。按住 `Fn` 键的同时按 `ScrLk` 键可启用或禁用此模式。

## 开始使用你的鼠标

我们的官方鼠标有三个按钮，可以激活高质量的微动开关。滚轮用于在浏览文档和网页时快速滚动。

![鼠标](https://www.raspberrypi.com/documentation/accessories/images/the-mouse.png)

使用时请始终把鼠标放在平坦稳定的表面上。鼠标通过光学方式检测其所在表面的移动。在无纹理特征的表面上（例如 PVC 或亚克力桌面），鼠标无法检测移动。如果需要在这样的表面上工作，请把鼠标放在鼠标垫上。

## 把所有东西连接起来

这是我们推荐的配置，可同时使用你的树莓派、官方键盘及其集线器以及官方鼠标。键盘上的集线器便于访问 USB 存储设备，鼠标线缆既整齐又足够长，使你能够用左手或右手操作鼠标。

![everything](https://www.raspberrypi.com/documentation/accessories/images/everything.png)

>**注意**
>
> 请注意，要把电源接入树莓派，然后把键盘连接到树莓派。如果把电源接入键盘，再由键盘为树莓派供电，键盘将无法正常工作。
